Kartbi V19: GitHub Actions ile günlük kaynak kontrolü. Workflow sadece rapor artifact üretir; kampanya toplamaz, yayınlamaz. GitHub Pages için mevcut main/root ayarı değişmez. Workflow yüklemek için GitHub web arayüzünde .github/workflows/source-watch.yml dosyasını Create new file ile eklemek gerekebilir. İlk çalıştırma: Actions > Kartbi source availability watch > Run workflow. Hash geçmişi Actions cache ile saklanmaya çalışılır; cache kaybolursa değişiklik durumu bilinmiyor olarak raporlanır.
