Kartbi V38 — inceleme kararlarının GitHub üzerinde saklanması
1. admin.html sayfasına GitHub Actions source-watch raporunu yükleyin.
2. Kararları inceleyin ve JSON olarak indirin.
3. İndirilen dosyayı monitor/review_decisions.json yoluna yükleyin.
4. Tercihen Pull Request açın; review-validation.yml kararların biçimini ve kaynak URL eşleşmesini kontrol eder.
5. Bu bir kayıt/denetim sürecidir; kampanya verilerini değiştirmez ve banka koşullarını doğrulamaz.
6. GitHub Pages üzerinde admin.html herkese açıktır; gizli bilgi veya müşteri verisi eklemeyin.
